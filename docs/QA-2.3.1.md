# CHARONOS 2.3.1 검증 기록

검증일: 2026-10-15 (Asia/Seoul). Windows x64, MSVC 2022, Qt 6.10.3, FFmpeg, Release.

`tools\test-features.bat` 결과: **28 passed, 0 failed**. 검사 빌드의 `CHARONOS.exe` 파일/제품 버전은 2.3.1입니다.

## 프레임별 상태 유지

- 기존에는 편집 대상 프레임을 `keyAt(현재 프레임)`으로 골라 이전 키를 직접 수정했습니다. 이제 현재 프레임의 상태를 복사하고 그 프레임에 저장합니다. 같은 값으로 편집한 경우에는 키를 만들지 않습니다.
- 펜, 선, 화살표, 사각형, 원, 텍스트, 이미지의 10프레임 상태를 만든 뒤 26프레임에서 이동·회전·크기·가로/세로 늘이기를 변경했습니다. 10~25프레임 보존, 26프레임부터 변경, 이후 40프레임의 기존 키 보존을 확인했습니다.
- 중간의 더 이른 프레임에서 여러 개 선택 후 색상·불투명도를 바꾸어도 이전 키와 이후의 변경 키가 유지됩니다.
- 실행 취소/재실행 및 프로젝트 저장/재열기에서 서로 다른 상태가 유지됩니다.
- 비교 B를 편집해도 A와 B의 이전 키가 바뀌지 않습니다. 뒤 프레임의 일부 삭제, 지우개로 전부 삭제한 빈 키, 실행 취소/재실행을 검사했습니다.
- 트래킹 결합/해제와 이동 보정은 해당 프레임의 주석 키에 저장되며 기존 트래킹 움직임은 계속 평가됩니다. 기존 트래킹/내보내기 검사를 새 규칙에 맞춰 통과했습니다.
- 드래그를 놓기 전에 프레임을 이동해도 이전 프레임에 변경을 확정하고, 같은 값으로 편집했을 때 중복 키가 생기지 않는지 검사했습니다.

## RGB 채널

- Video > Color Channels의 상호 배타적 RGB / Red / Green / Blue 메뉴를 검사했습니다.
- OpenGL 프레임버퍼에서 단일 화면, Wipe, Side by Side, Top/Bottom, Blend의 A/B 픽셀을 직접 읽었습니다. 선택한 채널의 원래 값 유지와 나머지 두 채널의 0 표시를 확인했습니다.
- 영상 어니언 스킨에도 같은 필터가 적용되는지 픽셀로 확인했습니다. 필터는 뷰어 영상에 적용되며 주석과 내보내기 영상의 색상은 바꾸지 않습니다.

## 텍스트 옵션

- 텍스트 상자 위의 옵션창 위치, 숫자 컨트롤·굵게·기울임 버튼을 클릭하는 동안 편집 유지, 글꼴과 스타일의 실제 편집기 반영을 검사했습니다.
- 글꼴, 크기, 굵게, 기울임, 불투명도, 배경 사용을 바꾼 후 내용을 바꾸지 않고 적용해도 새 프레임에 스타일이 저장됩니다. 이전 프레임 스타일은 유지됩니다.
- 취소하면 상속 프레임에 키가 생기지 않습니다. 컨트롤에 포커스가 있는 채 프레임을 이동해도 원래 편집 프레임에 저장되며 실행 취소/재실행됩니다.
- 입력 중 프로젝트 저장 시 텍스트와 스타일 확정, 저장/재열기, 옵션창 닫힘을 확인했습니다. 기존 현재 프레임 내보내기의 입력 확정 검사도 통과했습니다.
- `qa-text-options.png`를 직접 확인해 옵션창과 텍스트가 겹치거나 컨트롤이 잘리지 않는 것을 확인했습니다.

## 범위

기존 재생/캐시, 프레임 출력, 동영상 인코딩, 폴더 가져오기, 단축키, 캔버스 및 필압 이벤트 검사를 함께 통과했습니다. 모든 가능한 입력 순서, 실제 타블렛 하드웨어 및 모든 GPU/디스플레이 배율을 검증했다는 뜻은 아닙니다.
