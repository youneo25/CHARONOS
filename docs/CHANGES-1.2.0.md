# CHARONOS 1.2.0

2026-11-03 (Asia/Seoul)

## 새 기능

- **처음 화면 정리**: 새로 설치하면 Project View와 Default Timeline 패널만 보입니다. 주석 도구 막대, 클립 바, 타임라인 편집기 같은 다른 도구는 숨겨진 상태로 시작하고, **창** 메뉴에서 언제든 켜고 끌 수 있습니다. **창 > 레이아웃 초기화**는 이 시작 화면으로 돌아갑니다.
- **첫 실행 설정 창**: 처음 설치했을 때 한 번만 나옵니다. 언어(English / 한국어), 시작할 때 보일 패널, 메모리 사용량(가볍게 / 균형 / 높게), 적응형 메모리, 하드웨어 디코딩, 내보내기 폴더, 시작 시 업데이트 확인을 정할 수 있습니다. 건너뛰면 기본값을 씁니다.
- **업데이트 알림**: 시작할 때 GitHub에 새 버전이 있으면 알려 줍니다. **지금 업데이트**는 설치 파일을 받아 실행하고, **나중에**를 누르면 그 다음 버전이 나올 때까지 다시 묻지 않습니다. **도움말 > 업데이트 확인...** 으로 언제든 확인할 수 있습니다.
- **새 비교(Compare) 모드**: 비교 버튼을 누르면 뷰어 위에 비교 바가 열립니다.
  - A와 B를 목록에서 바로 고르고, ⇄ 버튼으로 바꿉니다.
  - 보기 방식: 좌우(기본) / 위아래 / 와이프 / 겹쳐 보기(50%).
  - 동기화: 시간 기준 / 프레임 기준, **B 오프셋**(프레임 단위로 B를 앞뒤로 밀어 레퍼런스와 타이밍 맞추기, Alt+[ / Alt+]).
  - 주석 대상(A / B)과 소리(자동 / A / B)도 바에서 바로 고릅니다. 기존 단축키(Shift+0~4, Tab, Shift+Tab)도 그대로 동작합니다.
- **새 내보내기 창**: 다빈치 리졸브 / 프리미어 프로처럼 왼쪽 프리셋, 가운데 비디오 / 오디오 / 오버레이 탭, 오른쪽 미리보기와 요약(코덱, 해상도, 길이, 예상 파일 크기), 아래 파일 이름과 저장 위치로 정리했습니다. 형식(MP4 / MOV / 이미지 시퀀스)과 코덱을 따로 고릅니다.
- **CHARONOS Lite**: 타임라인 편집기, 모션 그래프, MCP / AI 연동을 뺀 가벼운 버전입니다. Windows용과 **Android용 APK**가 있습니다. 프로젝트 파일(.frvm)은 정식 버전과 같습니다.
- **Android (Lite)**: 휴대폰과 태블릿 화면 비율에 맞춰 배치가 바뀝니다(세로 화면에서는 뷰어가 위, 패널이 아래). 펜(필압) 지원, 두 손가락 확대 / 이동, 세 손가락 좌우 드래그로 프레임 스크럽, 길게 누르면 우클릭 메뉴. 펜을 쓰면 손가락으로는 그려지지 않습니다(도구 > 펜으로만 그리기). 앱이 백그라운드로 가면 프로젝트를 자동 저장합니다.
- **Android ↔ Windows 프로젝트 호환**: 다른 기기에서 저장한 프로젝트를 열 때 미디어 경로가 없으면 프로젝트 폴더(하위 2단계, 상위 폴더 포함)에서 같은 이름의 파일을 찾아 연결합니다. 미디어를 프로젝트 옆에 두고 폴더째 옮기면 그대로 열립니다.

## 메모리 최적화

- 프레임 캐시 기본값을 RAM의 50%에서 **25%(최대 8 GB)**로 낮췄습니다. 도구 > 캐시 메모리에서 프리셋이나 직접 크기를 정할 수 있습니다.
- **적응형 메모리**: 시스템 RAM이 부족해지면 캐시를 자동으로 줄였다가, 여유가 생기면 천천히 다시 늘립니다.
- 창을 최소화하고 20초가 지나면 캐시의 대부분을 반납하고 백그라운드 채우기를 멈춥니다(Android: 백그라운드로 가면 바로).
- 20초 동안 쓰지 않은 소스의 디코더는 코덱 버퍼(프레임 스레드 버퍼 포함)를 반납합니다. 다음 프레임 요청 때 자동으로 다시 엽니다.
- 타임라인 썸네일 캐시에 상한을 두었고, 오디오 디코딩 마지막의 불필요한 전체 복사를 없앴습니다.
- 캐시 표시용 마스크를 0.25초마다 전부 다시 계산하던 것을 캐시나 시퀀스가 바뀔 때만 계산하도록 바꿨습니다.

## 버그 수정

- 타임라인에서 영상과 소리가 따로 움직이던 문제: 소스 목록 등 다른 곳에서 클립을 고른 뒤 드래그 / 미세 이동하면 연결된 소리가 남아 있던 문제를 고쳤습니다. 연결된 짝 중 하나가 잠긴 트랙에 있으면 둘 다 움직이지 않습니다(어긋나지 않도록). Alt+클릭으로 한쪽만 고르는 기능은 그대로입니다.
- 내보내기 기본 폴더가 개발 PC 경로(F:/Codex/...)로 되어 있던 문제를 고쳤습니다. 이제 `동영상\CHARONOS Exports`가 기본입니다.
- 이미지 시퀀스 내보내기에서 오디오 옵션이 켜져 보이던 문제, 형식을 바꿀 때 파일 확장자가 바뀌지 않던 문제를 고쳤습니다.
- Lite와 정식 버전이 함께 설치되어 있어도 .frvm 기본 연결을 서로 빼앗지 않습니다(Lite는 "연결 프로그램" 목록에만 추가).

## 실행

- 정식 버전: `CHARONOS-1.2.0-Setup-x64.exe` 또는 `CHARONOS-1.2.0-win64-portable.zip`
- Lite (Windows): `CHARONOS-Lite-1.2.0-Setup-x64.exe` 또는 `CHARONOS-Lite-1.2.0-win64-portable.zip`
- Lite (Android 8.0 이상, arm64): `CHARONOS-Lite-1.2.0-android-arm64.apk`. 처음 실행할 때 "모든 파일 접근"을 허용해 주세요. Android의 MP4 내보내기는 MPEG-4 비디오(+AAC)로 저장합니다(ProRes, 이미지 시퀀스는 Windows와 같음).
