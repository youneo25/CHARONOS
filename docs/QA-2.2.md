# CHARONOS 2.2 검증 기록

검증일: 2026-10-15 (Asia/Seoul)

환경: Windows 11 x64, MSVC 2022, Qt 6.10.3, FFmpeg shared DLL, Release 빌드.

`tools\test-features.bat`의 QtTest 결과: **18 passed, 0 failed, 0 skipped**. 원본 결과는 함께 제공된 `feature-results.txt`에서 확인할 수 있습니다. 초기에 Windows 임시 폴더에 대한 샌드박스 쓰기가 제한되어 검사 중 저장 실패가 발생했고, 검사 임시 파일을 빌드 작업 폴더 안에 생성하도록 수정한 뒤 전체 검사를 통과했습니다.

검사 내용:

- 시작 시 선택 도구, 프로젝트/Sources 외부 파일 드롭, 내부 타임라인 이동 이벤트 유지.
- 주석 종류별 가로/세로 크기 변형, 히트 검사, 필압 세 스타일.
- 트래킹 결합/해제, 위치 평가, 실행 취소/재실행, 프로젝트 저장 왕복.
- 주석/비디오 어니언 스킨과 비동기 프레임 갱신, A/B 그리드, B 편집.
- 재귀 폴더 드롭, 불필요한 파일 제외, 별개 이미지 분리, 번호 이미지 시퀀스 묶기, 프로젝트 폴더 저장.
- 단일 Pen 버튼의 스타일 동기화, 마우스 Shift 직선 및 타블렛 직선의 끝점 필압.
- 영상 바깥 A/B 주석 표시의 OpenGL 픽셀, 바깥 주석 히트 검사, 여백을 포함한 합성 출력 픽셀.
- 단축키 중복/접두 충돌 검사, Save/재실행/실제 키 입력, Shift+Tab 재지정 유지.
- 사용자 Export Preset 저장·재열기·전체 설정 복원·삭제.
- 영상 없는 2D 캔버스 생성, 주석 키, 실행 취소/재실행, `.frvm` 재열기, 재생, 실제 펜 드래그.
- 2D PNG 6프레임 출력 및 주석 픽셀, MP4 CPU H.264 인코딩 후 재디코딩 및 6프레임 확인.
- 2D 뷰어의 OpenGL 프레임버퍼에서 실제 그려진 선의 픽셀 확인.
- 앞/뒤 Endless Scrubbing, In/Out 범위 순환, 순환 해제, 타임라인 상대 드래그 이벤트.
- Console 명령으로 프레임/도구 전환, 상태/도움말 출력, 로그 패널 화면.

QA PNG는 Qt 창 캡처와 직접 읽은 OpenGL 프레임버퍼를 포함합니다. `qa-canvas-viewport.png`, `qa-outside-compare.png`는 실제 렌더링 픽셀 검사 대상입니다. QWidget 전체 캡처는 OpenGL 오버레이 합성을 완전히 반영하지 않을 수 있어 직접 프레임버퍼도 함께 검증했습니다.

배포 패키지는 Qt 플러그인, FFmpeg DLL, Microsoft C++ 런타임을 포함합니다. 패키징 스크립트는 배포 EXE의 원본/복사 해시와 ZIP 내부 모든 파일의 SHA-256을 비교합니다. F: 배포 폴더의 EXE 실행 검사는 빌드 후 별도로 수행합니다.

실제 타블렛 하드웨어, NVIDIA NVENC 인코더, 장시간 대규모 프로젝트 부하 검사는 수행하지 않았습니다. 입력 이벤트/CPU 인코딩 및 렌더링 검사를 통과했다는 범위에서 결과를 확인하세요.
