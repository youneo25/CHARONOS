# CHARONOS 1.1.1 수정본

2026-10-22 (Asia/Seoul)

- SOURCES 목록의 미디어를 타임라인으로 드래그해 원하는 위치·트랙에 추가할 수 있습니다. 여러 소스를 함께 끌면 순서대로 배치됩니다. 원본 소스는 목록에 남습니다.
- 스냅, 리플/덮어쓰기, 영상·오디오 연결, 실행 취소/다시 실행과 함께 동작합니다. 잠긴 트랙에는 드롭할 수 없습니다.
- 서로 다른 FPS의 영상을 이어 붙일 때 다음 영상의 오디오가 느려지거나 음높이가 바뀌던 문제를 수정했습니다. 소스의 실제 시간과 타임라인 시간을 변환해 영상 길이와 오디오 속도를 유지합니다.
- 24·30·60·29.97fps 및 가변 FPS 시간 매핑을 검사했습니다. 44.1kHz 오디오도 정상 속도로 재생됩니다.
- 자르기·분할·파형·주석 위치·다중 트랙 재생과 MP4 내보내기에 같은 시간 매핑을 적용했습니다. 원본 프레임 사이에서 자른 지점도 프로젝트에 정확하게 저장됩니다.
- 타임라인 FPS를 바꾸면 클립의 초 단위 위치와 오디오 속도를 유지하며, 실행 취소로 이전 FPS를 복원할 수 있습니다.
- 최초 실행 시 타임라인은 숨깁니다. 이후에는 정상 종료 때 타임라인을 켜 두었으면 다음 실행에서도 켜고, 꺼 두었으면 계속 숨깁니다. 임시 '뷰어만 보기' 모드로 종료해도 원래 표시 상태를 기억합니다.

## 실행

`CHARONOS-1.1.1-win64/CHARONOS.exe`를 실행하세요. 포터블 ZIP을 다른 위치에 풀어 실행해도 됩니다. 기존 1.1.0 배포 파일은 덮어쓰지 않았습니다.

기존 프로젝트의 클립 시작 위치는 그대로 유지합니다. 서로 다른 FPS 때문에 길이가 잘못 늘어나 있던 클립은 올바른 길이로 표시되므로, 기존 편집에서 생기는 빈 구간은 타임라인에서 조정할 수 있습니다.

검증 기록은 `QA-1.1.1/`에 있습니다.
