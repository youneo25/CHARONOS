# CHARONOS 2.2 사용 안내

Windows x64 포터블 배포입니다. ZIP 전체를 풀고 `CHARONOS.exe`를 실행하세요. DLL과 하위 폴더를 함께 유지해야 합니다.

## 추가된 기능

1. **Sources 폴더**: Sources 탭 아래 폴더 버튼을 클릭하거나 `Ctrl+Shift+I`로 폴더를 가져옵니다. 하위 폴더까지 읽고, 번호가 이어지는 이미지는 하나의 시퀀스로 묶습니다. 영상·이미지 이외의 파일은 건너뜁니다. 폴더 버튼 우클릭 또는 목록 우클릭의 **New Folder**로 프로젝트 정리용 폴더를 만듭니다. Project View의 SOURCES에 표시되며 소스 우클릭 **Move to Folder**로 이동할 수 있습니다. 폴더 이름 변경·제거가 가능하고, 폴더 제거 시 소스는 유지됩니다. 프로젝트 저장에 포함됩니다. 타임라인 재생 순서는 기존 Sources 목록에서 관리합니다.

2. **단일 Pen 버튼**: 왼쪽의 그리기 버튼 하나를 우클릭하여 Pencil / Pen / Highlighter를 선택합니다. 버튼 아이콘이 현재 스타일을 표시하며 마지막 스타일을 기억합니다. 기존 `P / N / B`도 사용할 수 있습니다. 세 스타일 모두 타블렛 필압을 받습니다.

3. **Shift 직선**: 마우스나 타블렛으로 그리는 동안 Shift를 누르면 시작점부터 현재 위치까지 직선으로 그립니다. 도중에 Shift를 누른 경우도 해당 스트로크가 직선으로 바뀝니다. 타블렛은 시작·끝 필압을 유지합니다.

4. **HotKey Manager**: Tools > HotKey Manager 또는 `Ctrl+Alt+K`. 명령 검색, 키 지정·해제, 중복·겹침 검사, 기본값 복원을 지원합니다. Save로 즉시 적용되며 다시 실행해도 유지됩니다. Cancel은 변경을 버립니다. 단축키를 변경하면 이 안내의 기본 키 대신 변경한 키를 사용하세요.

5. **영상 바깥 주석**: 영상 경계 바깥에도 펜, 도형, 텍스트를 만들고 선택·편집할 수 있습니다. A/B 비교에서는 각 편집 영역의 영상 바깥 공간까지 표시합니다. 확대·화면 이동으로 영역을 확보하세요. 내보내기의 **Canvas Border**를 10 / 25 / 50 / 100%로 설정하면 각 가장자리에 영상 크기 대비 여백을 추가합니다. 여백 안의 주석이 포함되고 출력 해상도도 커집니다. 0%는 기존 영상 크기로 출력합니다.

6. **2D 애니메이션**: File > New 2D Animation 또는 `Ctrl+Alt+N`. 이름·크기·프레임 수·FPS를 지정하면 영상 파일 없이 캔버스가 생성됩니다. 프로젝트에 추가되며 다른 소스와 함께 사용할 수 있습니다. 주석 키, 이전 키 유지, 빈 키, 선택·변형, 어니언 스킨, 실행 취소, 재생, 프로젝트 저장, 영상/이미지 시퀀스 내보내기를 지원합니다. 캔버스 배경은 짙은 회색입니다. 기본은 1920×1080, 240프레임, 24fps입니다. 새로운 프레임에 그리면 새 키가 만들어지고, Edit > Continue Previous Drawing을 켜면 이전 그림에 이어 그립니다.

7. **Export Presets**: 내보내기 창의 Preset에서 Review MP4 / Compact MP4 / ProRes Master / 2D PNG Sequence를 선택합니다. 현재 형식·범위 종류·FPS·축소율·여백·주석·캡션·트래킹·오디오·비교 설정을 Save로 이름을 붙여 저장할 수 있습니다. 사용자 프리셋은 다음 실행에서도 유지되며 Delete로 제거합니다. 출력 경로는 프리셋에 포함하지 않습니다. In/Out이 없는 프로젝트에서 해당 범위 프리셋을 불러오면 가능한 범위로 조정합니다.

8. **Console**: Tools > Console 또는 Ctrl+백틱 키로 열고 닫습니다. Qt와 FFmpeg의 정보·경고·오류 및 앱 작업 메시지를 표시합니다. 최대 2000줄을 유지하며 로그 저장·비우기를 지원합니다. 입력 가능한 명령은 `help`, `status`, `frame 12`, `play`, `pause`, `tool pen`, `clear cache`입니다. 프레임 번호는 0부터 시작합니다. 명령은 앱 안에서 동작합니다.

9. **Endless Scrubbing**: 뷰어에서 Alt+왼쪽 드래그, 타임라인에서 Alt+왼쪽 드래그 또는 가운데 드래그. 커서가 화면 가장자리에 도달하면 반대쪽으로 이동하고, 시퀀스 끝에서는 처음으로 이어집니다. In/Out 반복이 활성화되어 있으면 그 범위 안에서 순환합니다. Shift를 함께 누르면 18px당 1프레임으로 미세 조절합니다(기본 6px당 1프레임). Tools > Endless Scrubbing을 끄면 커서·재생 범위 순환을 중지합니다. 타임라인의 일반 왼쪽 드래그는 기존 절대 위치 탐색입니다.

## 저장과 내보내기

프로젝트 형식은 `.frvm` v5입니다. 기존 v3/v4 및 이전 JSON 프로젝트를 읽을 수 있습니다. 2D 캔버스 및 폴더가 포함된 새 프로젝트는 이 버전에서 여세요.

내보내기 기본 위치는 `F:\Codex\outputs\날짜\charonos-exports\`이며, 이전에 선택한 저장 폴더가 있으면 해당 설정을 유지합니다. 재생 FPS와 출력 FPS의 기존 프레임 대응 방식은 유지됩니다. PNG 시퀀스는 각 키의 그림이 유지되는 프레임도 모두 출력합니다.

## 검증 범위

실제 Qt 창, OpenGL 프레임버퍼 픽셀, 마우스·필압 이벤트, 프로젝트 저장 왕복, 단축키 저장 및 재실행, 프리셋 저장·삭제, 2D 재생, CPU H.264 MP4 및 PNG 출력으로 검사했습니다. 실제 타블렛 장치와 NVIDIA 하드웨어 인코더의 장치별 동작은 별도 환경 확인이 필요합니다.
