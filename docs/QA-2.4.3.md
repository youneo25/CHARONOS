# CHARONOS 2.4.3 검증

검증일: 2026-10-15 (Asia/Seoul).

## 변경 동작

- Tracking > Tracking Manager(트래킹 매니저): 오른쪽 패널을 열고 닫습니다. 패널 자체의 닫기 버튼도 지원합니다.
- 전체 트래킹 오버레이 표시: 기존 Tracking > Show Tracks와 동기화합니다.
- 현재 편집 클립의 트랙 목록: 트랙 선택, 표시 체크박스, 생성 이전 숨김 체크박스, 생성 프레임을 제공합니다. A/B 비교에서는 현재 편집 중인 쪽을 따릅니다.
- ‘생성 이전 숨김’은 기본 ON입니다. 생성 프레임 이전에는 마커와 전체/최근 경로를 모두 숨기며, OFF로 바꾸면 이전 프레임의 추적 결과도 표시합니다. 숨긴 마커는 클릭/드래그 대상으로 잡히지 않습니다.
- 생성 프레임은 역방향 추적·보정과 별도로 저장합니다. 이전 프로젝트에 생성 정보가 없으면 가장 이른 수동 키를 사용하고, 수동 키도 없으면 가장 이른 추적 지점을 사용합니다. 이전 프로젝트에서 실제 최초 생성 시각을 복원할 수는 없습니다.
- 트랙별 표시/생성 이전 숨김은 실행 취소·다시 실행 및 프로젝트 저장에 반영됩니다. 이미지/영상 출력에도 동일하게 적용하며, 숨긴 트랙은 이미지 출력의 여백 계산에서 제외합니다.
- 텍스트 Inspector: 글꼴 목록 오른쪽에 테두리와 화살표가 있는 30px 버튼을 추가했습니다. 불투명도는 0–100% 슬라이더와 큰 글자·높은 대비의 퍼센트 입력칸을 함께 사용합니다. 두 값은 서로 동기화됩니다.
