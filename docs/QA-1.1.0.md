## 1. 다중 트랙 타임라인

- 모델: `TimelineClip`에 종류(비디오/오디오), 트랙, 시작 프레임, 켜기/끄기, 연결(link), 이름, 라벨 색, 합성(불투명도·크기·위치·블렌드), 소리(게인·음소거·페이드)를 추가. 트랙마다 이름·보이기·잠금·솔로·게인(`TrackState`). 캔버스 크기(자동 = 첫 클립).
- 편집 엔진 `src/model/TimelineModel.*` (UI와 분리, 단독 검사 가능): 덮어쓰기 이동(겹친 클립을 자르거나 나눔), 리플 이동(경계에 삽입), 일반/리플 트림, 연결 유지 분할, 리프트/리플 삭제, 갭 닫기, 삽입, 이웃과 순서 바꾸기, 트랙 재배치. 리플은 편집한 트랙과, 그 구간이 비어 있는 다른 잠기지 않은 트랙을 함께 밀어 싱크를 유지.
- 뷰어가 편집하는 그림 = 재생 위치의 가장 위 보이는 클립(변형 없는 클립 우선 — PiP 인셋 아래의 전체 화면 클립이 편집 대상). 나머지 트랙은 아래→위 순서로 GPU에서 합성. 불투명한 전체 화면 클립 아래 트랙은 디코딩하지 않음.
- 갭: 검은 화면(파일이 없으면 "Media Offline"), 재생·오디오가 그대로 지나감.
- 검사 `timelineEngineOverwriteRippleAndLayers`: 1.0 클립이 이어서 배치, 덮어쓰기 이동이 앞 클립 꼬리를 자름, 리플 삽입이 클립을 나누고 밂, 리프트/리플 삭제, 일반 트림이 이웃에서 멈춤·리플 트림이 밂, 연결 분할(머리–머리, 꼬리–꼬리), PiP 우선순위·숨긴 트랙, 리플 이동 삽입점, 편집점, Alt 복제, 잠긴 트랙.
- 검사 `multiTrackViewerCompositesAndGaps`: 실제 영상 2개로 V2 인셋(오른쪽 위 35%)이 V1 위에 보이는지, Difference 블렌드 색, 트랙 숨기기, 갭 프레임, 인셋만 남았을 때 주석 좌표가 클립 변형을 따르는지, 실행 취소.
- 검사 `timelineEditorMouseKeysAndUndo`: 타임라인 위젯에 실제 마우스·키 이벤트 — 드래그 이동(갭 생김), 맨 위로 끌어 새 V2, 머리 트림, 블레이드 클릭, Delete(갭 유지)·Shift+Delete(리플), S/B/V, Alt+→ 미세 이동, D 끄기, Ctrl+C/V 붙여넣기, 리플 모드 드래그 = 순서 바꾸기.

## 2. 주석 클립 (DaVinci Resolve 방식)

- 주석은 1.0처럼 소스 프레임의 키로 저장(호환). `src/model/NoteClips.*`가 키를 객체별 표시 구간으로 풀어, 함께 그린 객체(같은 clip id)를 블록으로 보여 줌. 블록 편집(이동·트림·분할·복제·삭제·레인·색·잠금) 후 키를 다시 써서 화면이 블록과 정확히 같게 유지. 새 필드(`clip`, `lane`, `clipColor`)는 1.0이 모르는 키로 보존됨.
- 아이콘: 텍스트 **T**, 드로잉 연필/펜/형광펜, 도형 사각형·원·화살표·직선, 이미지. 레인은 위로 갈수록 위에 그려짐(겹치면 다음 레인으로 자동 배치). 레인 보이기/잠금, 블록 클릭 = 뷰어에서 객체 선택.
- 기존 빨간 주석 마커(재생 바·클립 바)는 그대로.
- 검사 `annotationClipsMoveTrimSplitDuplicateAndLanes`: 블록 인식(드로잉 2획, 텍스트), 이동·트림·분할(새 객체 id)·겹치는 복제가 레인 1로 쌓이고 위에 그려짐, 레인 지정, 색, 삭제, 같은 키의 새 획이 같은 클립에 합류, JSON에 `clip`/`lane` 저장.
- 검사 `annotationLanesInEditorAndViewer`: 이어 그리기로 레인 0/1, 빨간 마커 유지, 레인 숨기기가 뷰어에서 해당 주석만 숨김, 블록 드래그·꼬리 트림·클릭 선택, 실행 취소, 뷰어 픽셀(주석 선이 실제로 그려짐).

- 영상 파일의 소리는 같은 번호 오디오 트랙의 연결 클립. 파형(소스 프레임당 8구간 피크, 게인 반영), 게인 선 드래그, 페이드 핸들, 클립 음소거, 트랙 M/S/게인.

## 6. 검사 중 발견해 고친 문제

1. **Otsu 임계값**이 두 덩어리 히스토그램에서 어두운 쪽 끝을 골라 실루엣이 반투명해짐 → 최대값 구간의 가운데를 사용.
2. **세로 드래그**: 미리보기에서 트랙이 추가되면 행 번호가 바뀌어 클립이 새 트랙으로 가지 않음 → 누른 행을 (종류, 트랙)으로 기억.
3. **맞닿은 클립**: 다음 클립의 머리를 잡으려 해도 앞 클립 꼬리가 잡힘 → 포인터가 들어 있는 클립 우선(주석 블록도 같은 방식).
4. **어니언 스킨 고스트**가 위 트랙 위에 그려짐(트랙 순서 위반) → 고스트를 자기 클립 바로 위, 위 트랙 아래에 그림.
5. 타임라인 포커스에서 **Ctrl+C/V/X/A**가 창 전체 단축키(주석 복사 등)로 새어 나감 → 타임라인이 먼저 처리.
6. **Shift+O**(Out 이동)가 어니언 스킨과 충돌 → Alt+I / Alt+O.
7. **클립 끝까지 유지되는 주석 블록**을 뒤로 옮길 수 없음 → 소스 끝에서 꼬리가 짧아지며 이동.
8. 1.0 `tools/test-features.bat`에서 windeployqt와 ffmpeg 명령이 한 줄로 붙어 있던 문제 → 분리, 1.1 검사 영상 생성 추가.

## 7. 알려진 제한

- 주석·트래킹은 그 프레임에서 편집하는 그림(가장 위 보이는 클립)의 것만 표시·편집. 아래 트랙 클립의 주석은 그 클립이 위에 올 때 보임.
- 클립 변형은 프리셋·클립 속성(숫자)으로 설정(뷰어에서 직접 끄는 핸들은 없음).
- 역방향 셔틀과 1× 초과 셔틀은 소리 없이 재생.
- 움직임 실루엣은 고정 카메라를 가정(플레이트 = 소스 전체 25프레임의 중앙값).
- 트랙 스위치(보이기·잠금·음소거·솔로)는 실행 취소 단계가 아님(프로젝트에는 저장).
- 1.0으로 1.1 프로젝트를 열면 트랙·갭·소리 클립은 무시됨.
- 실제 타블렛 장치 필압은 1.0과 같이 별도 검사하지 않음. `repeatedSpaceStartsFromDisplayedFrame`은 다른 앱이 포커스를 잡고 있으면 창 활성화 대기에서 실패할 수 있음(최종 실행에서는 통과).
