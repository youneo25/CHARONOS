# CHARONOS 2.3.2 사용 안내

2.3.2에서는 텍스트 글꼴 목록의 붉은 TT 배지를 밝은 회색 선형 T 아이콘으로 바꿨습니다. 선택 시에는 밝게, 비활성 상태에서는 흐리게 표시합니다. 글꼴 이름 및 문자 샘플 미리보기는 유지합니다.

## 2.3.1: 프레임별 편집, 채널 보기, 텍스트 옵션

10프레임에 만든 원을 26프레임에서 이동·회전·크기 변경하면 10~25프레임은 원래 상태를 유지하고 26프레임부터 변경됩니다. 변경한 상태는 다음 명시적 주석 키 전까지 유지됩니다. 이후에 이미 있던 키는 바뀌지 않습니다. 원뿐 아니라 펜, 선, 화살표, 사각형, 텍스트, 이미지, 여러 개 선택, 색상/불투명도, 삭제와 지우개, 비교 화면 B에도 같은 규칙을 적용합니다. 지우개로 전부 지운 프레임에는 빈 키를 만들어 이후 이전 그림이 다시 나타나지 않게 합니다. 실행 취소하면 새 키가 제거되고 원래 이어받기 상태가 복원됩니다.

트래킹에 연결된 주석은 기존 트래킹 움직임을 계속 따릅니다. 해당 프레임에서 주석을 직접 변경한 값만 별도 키에 저장합니다. 새 그림을 추가할 때 이전 그림도 유지하려면 기존 **Edit > Continue Previous Drawing / 편집 > 이전 주석에 이어 그리기**를 켭니다.

**Video > Color Channels / 비디오 > 색상 채널**에서 **RGB (전체)**, **Red만 보기**, **Green만 보기**, **Blue만 보기**를 선택합니다. 단일 채널 모드는 다른 두 색상 성분을 0으로 표시합니다. A/B의 모든 비교 방식 및 영상 어니언 스킨에 적용됩니다. 주석과 트래킹의 표시 색은 유지하며, 저장 파일과 내보내기는 원래 영상 색을 사용합니다.

텍스트(T)를 추가하거나 텍스트를 더블클릭하면 입력 상자 위에 옵션창이 표시됩니다. 글꼴, 크기(미디어 픽셀), 굵게, 기울임, 글자색, 불투명도, 배경 사용과 배경색을 바꿀 수 있습니다. **Apply / 적용** 또는 Enter로 확정하고 **Cancel / 취소** 또는 Esc로 변경을 취소합니다. Shift+Enter는 줄바꿈입니다. 옵션을 조작하는 동안 입력 상태가 유지됩니다. 다른 프레임/클립으로 이동하거나 저장하면 편집하던 프레임에 확정합니다. 화면 위쪽에서는 옵션창과 입력 상자가 겹치지 않게 배치됩니다.

## 설치

`CHARONOS-2.3.2-Setup-x64.exe`를 실행합니다. 한국어/영어 설치 마법사에서 설치 위치, 시작 메뉴 및 바탕화면 바로 가기를 선택할 수 있습니다. 기본 위치는 현재 사용자의 `AppData\Local\Programs\CHARONOS`이며 관리자 권한이 필요하지 않습니다. Windows 설정의 설치된 앱 또는 설치 폴더의 `unins000.exe`에서 제거합니다. 사용자 프로젝트는 제거 대상에 포함하지 않습니다.

Qt, FFmpeg, Microsoft C++ 런타임을 함께 포함하므로 별도로 개발 도구를 설치할 필요가 없습니다. 이 배포 파일은 코드 서명되지 않았습니다.

## 새 프로젝트

**File > New Project / 파일 > 새 프로젝트 (Ctrl+N)**를 누르면 별도 창에서 다음을 선택합니다.

- **동영상 리뷰 / 빈 프로젝트**: 이름을 입력하고 만든 뒤 영상이나 이미지 시퀀스를 가져옵니다.
- **2D 애니메이션**: 이름, 너비, 높이, 프레임 수, FPS를 지정해 영상 없는 캔버스를 만듭니다.

기존 `Ctrl+Alt+N`은 같은 창을 2D 애니메이션 선택 상태로 엽니다. 기존 프로젝트에 저장하지 않은 변경이 있으면 ‘만들기’ 이후 저장 여부를 묻습니다. 선택 창에서 취소하면 기존 프로젝트를 유지합니다. 새 2D 프로젝트를 만들면 기존 프로젝트를 대체하므로, 기존 작업은 먼저 저장하세요.

## 현재 프레임 이미지

**File > Export Frame / 파일 > 현재 프레임 저장 (Ctrl+Shift+E)**에서 옵션 창이 열립니다. 재생을 멈추고 입력 중인 텍스트를 확정한 뒤 저장합니다.

| 옵션 | 동작 |
|---|---|
| 파일 형식 | PNG, JPEG, TIFF |
| 출력 배율 | 원본 좌표를 기준으로 10–400% |
| 바깥 내용 자동 포함 | 기본 켜짐. 원본 영상과 현재 주석의 합집합으로 영역을 계산해 영상 밖 내용까지 저장 |
| 바깥 여백 | 자동 영역 바깥에 원본 픽셀 기준 여백 추가 |
| 배경 | 검정, 흰색, 투명. 투명은 PNG/TIFF에서 사용 가능 |
| JPEG 품질 | 1–100 |
| 영상 / 캔버스 포함 | 끄면 주석 또는 트래킹만 내보내기 가능 |
| 주석 / 편집 이미지 포함 | 이동, 회전, 크기 변경, 트래킹 연결 위치를 반영 |
| 트래킹 경로 | 현재 경로 표시 범위 설정을 반영 |
| 클립 이름 / 프레임 | 하단에 캡션 표시 |

옵션 창에는 저장할 클립, 프레임 번호, 예상 출력 크기를 표시합니다. 마지막으로 성공한 저장 옵션을 다음 실행에서도 유지합니다. A/B 비교 중에는 현재 편집하는 쪽의 클립을 저장합니다. 비교 화면 전체가 필요하면 기존 동영상/이미지 시퀀스 내보내기의 A/B 비교 옵션을 사용하세요. 그리드, 선택 핸들, 어니언 스킨은 현재 프레임 이미지에 포함하지 않습니다.

바깥 내용 자동 포함을 끄면 원본 영상 영역으로 자릅니다. 자동 영역을 포함한 출력은 한 변 최대 16,384픽셀, 총 6,400만 픽셀로 제한하며 초과하면 배율을 줄이도록 안내합니다. 이 제한은 큰 이미지의 메모리 할당 실패를 줄이기 위한 것입니다.

## 재생 개선

선읽기 길이를 캐시 예산에 맞춰 제한하고 A/B 및 다음 클립에 사용할 공간을 남깁니다. 재생 중 전체 범위의 비필수 백그라운드 채우기를 멈춰 현재 프레임과 가까운 프레임을 우선합니다. 비활성 소스는 재디코딩하지 않으며, 정지 중 전체 캐시 채우기는 순회 위치를 기억합니다. 비교 B의 프레임이 도착했을 때 현재 표시할 프레임인 경우에 화면을 갱신합니다. 재생 타이머는 FPS에 따라 1–8ms 간격을 사용합니다.

이 변경은 소프트웨어 디코딩 및 RGBA 캐시 구조를 유지합니다. GPU 디코딩을 추가한 릴리스가 아닙니다. 실제 측정과 검증 범위는 `QA-2.3.md`를 참고하세요.

## 재현 빌드

`build.bat`로 Release를 빌드하고 `tools\test-features.bat`로 기능 검사를 실행합니다. Inno Setup 6.7.3 이상 컴파일러를 준비한 뒤 다음을 실행합니다.

```powershell
powershell -File tools\package-installer.ps1 -Compiler 'C:\path\to\ISCC.exe'
```

기본 배포 위치는 `F:\Codex\outputs\<서울 날짜>\charonos-2.3.2-installer-<고유ID>`입니다. `-BuildDir build-test`로 검사 빌드의 Release 실행 파일을 배포할 수도 있습니다. 설치 EXE, 실행 폴더, 소스 ZIP, QA 이미지 및 SHA-256 목록을 함께 만듭니다.

재생 경로 측정은 `playback_probe <영상 경로> <캐시MB>`로 실행합니다. 보고되는 공급 FPS는 디코딩과 캐시 전달을 측정하며 GPU 표시, 주석 그리기, 오디오 장치까지 합친 최종 화면 FPS는 아닙니다.
