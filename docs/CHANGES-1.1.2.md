# CHARONOS 1.1.2

2026-10-22 (Asia/Seoul)

- 타임라인에 소스를 드롭하면 타임라인이 키 입력을 받습니다. 드롭 직후 Delete로 추가한 클립을 삭제할 수 있습니다.
- Sources 탭에서 클립을 선택하거나 타임라인에 포커스가 있을 때 Delete 명령이 타임라인의 선택 항목을 처리하도록 수정했습니다. Shift+Delete, 숫자 키패드 Delete도 지원합니다. 영상 뷰어에 포커스가 있을 때는 기존 주석 삭제 동작을 유지합니다.
- 타임라인에서 주석 블록을 Delete로 삭제할 수 있으며, 잠긴 주석·주석 레인은 삭제하지 않습니다. 삭제는 실행 취소할 수 있습니다.
- N1·N2 등 주석 레인의 기본 높이를 24px에서 40px로 늘렸습니다. **각 레인의 아래 경계선을 위아래로 드래그**하면 24~240px 범위에서 개별 조절할 수 있습니다. 경계선에 포인터를 올리면 위아래 크기 조절 커서가 표시됩니다.
- 주석 레인의 아래 경계선을 더블 클릭하면 기본 높이 40px로 돌아갑니다. 조절한 높이는 다음 실행에도 유지되며, 레인을 키우면 세로 스크롤 범위도 함께 바뀝니다.

1.1.1의 SOURCES 드래그, 혼합 FPS 영상·오디오 속도 수정, 마지막 종료 시 타임라인 표시 상태 기억 기능도 포함합니다.

## 실행

기존 CHARONOS를 종료한 뒤 `CHARONOS-1.1.2-win64/CHARONOS.exe`를 실행하세요. 기존 1.1.0 및 1.1.1 배포 파일은 보존했습니다.
