CHARONOS 1.1 User Guide

CHARONOS is a frame-accurate reference player for animators. Load video or image sequences, lay them out on a multi-track timeline, study timing and spacing frame by frame, draw over the picture, read motion through silhouette filters, track motion, compare takes side by side, and keep review notes — with GPU-accelerated playback and an AI assistant connection built in.

Windows 10 / 11 · x64Frame-exact decodingMulti-track timelineSilhouette analysisNVDEC + GPU colour conversionBuilt-in MCP server

1Getting started

Install

Run CHARONOS-1.0.0-Setup-x64.exe. No administrator rights are needed; the default location is %LOCALAPPDATA%\Programs\CHARONOS. Qt, FFmpeg and the Microsoft C++ runtime are included. Uninstall from Windows Settings › Apps or with unins000.exe in the install folder — your projects are never removed.

Your first review in one minute

  1. Drag a video, an image sequence (drop any one frame) or a whole folder onto the window, or use File › Import Media Ctrl+I.
  2. Press Space to play. Step with ← / →; hold Alt and drag anywhere on the picture to scrub.
  3. Pick the pencil P and draw on the frame. A drawing holds until the next drawing key.
  4. Press K to bookmark key poses, then Ctrl+Space to play only those poses.
  5. Save the project with Ctrl+S (.frvm). Your media is referenced, not copied.
Tip. Press F1 at any time for the shortcut sheet. It always shows your current keys, including the ones you changed in Tools › HotKey Manager.

The interface language is English by default; switch to Korean in Tools › Language / 언어 (restart to apply).

3Media and projects

Supported media

  • Video: MP4, MOV, M4V, MKV, AVI, WebM, MXF, WMV, MPEG and GIF — anything FFmpeg decodes, including H.264, H.265/HEVC, AV1, VP9 and ProRes. Variable-frame-rate phone and screen recordings are handled exactly: frame N is always the N-th picture.
  • Image sequences: PNG, JPEG, TIFF, BMP, WebP, TGA. Import one numbered frame and the whole sequence is found (shot_0001.png, shot_0002.png…).
  • 2D canvas: File › New Project, type 2D Animation (or Ctrl+Alt+N) creates a blank canvas of any size, length and frame rate for drawing animation without video.

Importing

Drop files or folders on the window, the Project View, the Sources list or the Timeline panel. Import Folder Ctrl+Shift+I brings in a folder tree and keeps its folders in the Project View. New sources are added to the end of the timeline.

Projects

A project (.frvm, JSON) stores your sources, timeline and trims, drawings, bookmarks, frame notes, tracks and settings. Media paths are saved absolute and relative to the project, so a project folder can be moved together with its media. If a file is missing when you open a project, CHARONOS asks you to locate it. Older .frvm files and Electron-era .json projects open as well; 1.0 projects stay readable by earlier builds (they ignore trims and notes).

Audio

Sound is decoded once and played through the default Windows output. While sound plays, the sound card is the clock, so the picture always shows the frame you hear. Audio › Scrub Audio plays a short slice for every frame you step to. Use Audio Offset to compensate a Bluetooth or HDMI delay. Mute with Ctrl+M, change the volume with Ctrl+↑ / ↓.

Frames skip? Playback › Skip Frames to Keep Up is off by default so every frame is shown, even if playback has to slow down. Turn it on to keep real time on slow machines.

Tracks

From the top: annotation lanes (N1, N2 …) where every drawing, text or shape is a clip; video tracks (V1 at the bottom, V2 above it …); and below the centre line the audio tracks (A1, A2 …). The clip whose drawings you see and edit is the top visible one at the playhead; a picture-in-picture inset on a higher track leaves the full-frame clip under it editable.

Compositing

Right-click a video clip for Opacity, Composite Mode (Normal, Add, Screen, Multiply, Difference) and Picture in Picture presets. Difference turns pixels that match black: put your animation over the reference on V2 to see exactly where poses and timing differ. The canvas follows the first clip, or set a fixed size in Timeline › Timeline Settings…; clips of other sizes are fitted into it.

Sound

A video file's sound comes in as its own clip on the audio track of the same number, linked to the picture. Each sound clip shows its waveform (scaled by its gain). Drag the yellow gain line up or down (Shift for fine steps), drag the small squares at the top corners to set fades, or right-click for Clip Gain, Mute Clip and Fades. What you hear — and what is exported — is the mix of every audible sound clip.

Annotation clips

Drawings are shown as clips on the annotation lanes: T for text, a pencil (or pen / highlighter) for drawings, and shape icons for rectangles, ellipses, lines and arrows. Strokes drawn together at one key form one clip. Drag a clip to change when it appears or move it to another lane (higher lanes draw on top), drag its edges to change how long it stays, cut it with the blade or Cut at Playhead, Alt+drag to duplicate, Delete to remove. Right-click for Clip Color, Recolour drawing, End at Playhead, Hold to End of Clip, Set Duration…, Move to Lane and Lock. Clicking a clip selects its objects in the viewer. The red review marks on the scrub bar and the clip bar work as before.

How drawings hold

Drawings are stored per source frame as keys, like cels. Drawing on a frame without its own key starts a new key there; the previous drawing stops at that frame. A key holds until the next key. Editing a held drawing copies it to the current frame first, so earlier frames stay as they were. Clearing a frame (Shift+Del) adds an empty key. Turn on Edit › Continue Previous Drawing to keep the previous drawing and add to it instead.

Pens respond to tablet pressure (Wacom and Windows Ink); the mouse draws an even line. Width, opacity and text size are set in the stroke panel (the ≡ button), from 0.5 px up to 200 px. With a selection, colour and stroke changes apply to it.

Right-click a drawing for copy, duplicate, colour, stroke, bring to front / send to back, lock and delete. Drawings can follow a tracked point: select them, Shift+click a tracking marker and press Ctrl+J (Ctrl+Shift+J detaches).

7Onion skin

Toggle with Shift+O or the onion button; right-click the button (or Video › Onion Skin Settings) for the settings. CHARONOS ghosts both your drawings and the video itself, the way 2D animation packages and review players do:

SettingMeaning
Mode: drawings by keyThe previous / next drawings, however far away (like cel animation tools). Empty keys are skipped.
Mode: drawings by frame distanceWhat is on screen N, 2N, 3N… frames away. A drawing that is already on screen is never ghosted over itself.
Drawings before / afterHow many ghosts in each direction (0–8).
Video frames before / afterGhost the neighbouring video frames (0–8 each way) — ideal for reading spacing in reference footage.
Every N framesDistance between ghosts. 2 shows every other frame (animation on twos).
OpacityStrength of the nearest ghost; farther ghosts fade out to about a quarter of it.
Tint and coloursBefore ghosts are warm (red), after ghosts cool (green) by default; pick your own colours or turn tinting off to see true colours.
Show while playingGhosts are hidden during playback unless this is on.

The nearest ghosts are drawn on top. Video ghosts are decoded on purpose when they are not cached yet, so they appear a moment after you stop on a frame. In A/B compare, each side gets its own ghosts.

8A/B compare

Show a second source next to the current one: click its B badge in the Project View or Sources list, or use the compare button. Layouts: Wipe Shift+1 (drag the divider), Side by Side Shift+2, Top / Bottom Shift+3, Blend Shift+4 (50 %), off with Shift+0; swap A and B with Tab.

  • B follows A by time at its own frame rate (a 30 fps take against a 24 fps reference stays in sync). Turn off Video › Compare › Sync B by Time to match frame numbers instead.
  • Playback runs as long as the longer of the two; A holds its last frame if it is shorter.
  • Click on B (or press Shift+Tab in Blend) to draw, select, track and onion-skin on B. The side being edited has a thin orange outline.
  • Audio › Compare Audio chooses whose sound plays (Auto = A if it has sound, otherwise B).

9Motion tracking

  1. Choose the tracker M and click a high-contrast point (a joint, a prop corner).
  2. Press Ctrl+T to track forward or Ctrl+Shift+T backward. Esc stops.
  3. If the tracker drifts, drag the marker to the right spot: that frame becomes a hand key and later tracking never crosses it. Track again from there.

The path is drawn like a Maya motion trail, with a dot per frame and squares on hand keys. Shift+M switches between the recent path (1–10 s, fading) and the full path; Tracking › Frame Numbers labels the dots. Window › Tracking Manager lists the clip's tracks with per-track visibility and the option to hide a track before the frame it was created on. Right-click a marker to track, clear frames before / after, rename, recolour or delete.

10Motion Graph and key poses

Window › Motion Graph Ctrl+Alt+5 turns a tracked point into timing data:

  • X and Y position curves (screen up is up) and Speed — the distance moved per frame — as a filled curve. Click or drag on the graph to move the playhead.
  • A spacing chart underneath: one tick per frame, placed by distance travelled, exactly like the spacing guides animators draw. Bunched ticks are eases; wide gaps are fast moves.
  • Suggested key poses (dashed amber lines): frames where the point stops or reverses direction on either axis — contacts, extremes, the top of an arc. Holds give one key where the motion stops.
  • Bookmark Keys puts a bookmark on every suggestion, so Ctrl+Space immediately plays the action pose to pose. Copy CSV copies frame, x, y and speed for a spreadsheet.

The readout shows the position, speed in px/frame and px/second, and the change in speed (acceleration) at the playhead.

11Frame notes

Window › Frame Notes Ctrl+Alt+4 keeps written review comments on exact frames — timing, spacing, acting, pose notes. Type in the box and press Ctrl+Enter or Save Note; moving to another frame also saves what you typed. Ctrl+Shift+N jumps straight into the box. Esc discards the typing.

The list below shows every note in the project; double-click one to go there. Notes are saved in the project, are undoable, appear as amber dots on timeline clips, and can be exported with Export… as CSV (opens in Excel), Markdown or plain text — handy for sending feedback.

13Analysis filters (Filter menu)

Filters change how pictures are shown — never the media — to make motion easier to read. They apply to every video track, the A/B compare and video onion skin; drawings and tracks stay in colour on top. Press a filter's key again (or Alt+0) to go back to the picture.

FilterKeyUse it for
SilhouetteAlt+SThe subject as one solid shape, split by brightness (automatic threshold per clip). Reads poses, lines of action and negative space without detail.
Moving SilhouetteAlt+MWhatever differs from the shot's still background. CHARONOS builds a background plate from the median of frames across the clip, so busy backgrounds disappear. Best with a fixed camera.
Edge LinesAlt+EContours only, like a line drawing — shapes, overlaps and arcs.
ValueAlt+GBrightness only, for value and contrast checks.
NotanAlt+NTwo or three flat values: the big shapes of the frame.
Motion HighlightAlt+HWhat changed since the previous frame, in colour over a dimmed picture — spacing, arcs and holds at a glance while you step.

Filter › Filter Settings… Ctrl+Alt+F changes the filter live: threshold (or automatic), edge softness, how much of the picture shows behind the shape, a bright subject on a dark background, two or three notan values, and the shape, paper and motion colours. Rebuild Background Plate recomputes the plate of the clip under the playhead.

Exporting a filter. When a filter is on, the Export dialog offers Viewer Filter to burn it into the movie or image sequence — the same maths as the viewer.

15Exporting

Video and image sequences

File › Export… Ctrl+E renders the whole timeline, the current clip or the In/Out range:

  • MP4 H.264 (CPU, libx264) or H.264 / H.265 on the NVIDIA encoder (NVENC); MOV ProRes 422 HQ; PNG, JPEG or TIFF sequences.
  • Output frame rate and size, drawings burned in, tracks and trails, a caption with clip name and frame numbers, and a border so drawings outside the picture stay visible.
  • Audio is included (AAC in MP4, PCM in MOV) and follows the output frame rate.
  • With A / B compare layout on, the export reproduces the compare view, including B's drawings and sound.
  • Save your favourite settings as presets.

Still frames

File › Export Frame… Ctrl+Shift+E saves the current frame as PNG, JPEG or TIFF with scale, padding, background (black, white or transparent), and optional video, drawings, tracks and caption. The area grows automatically to include drawings outside the picture.

16Performance, GPU and NVDEC

  • GPU colour conversion. Decoded video stays in its native Y′CbCr form in memory (4:2:0 = 1.5 bytes per pixel instead of 4 for RGB) and is converted to RGB by the graphics card while it is displayed. The same cache therefore holds about 2.6× more frames (62.5 % less memory per 4:2:0 frame, 50 % for 4:2:2 ProRes). Colour matrix (BT.601 / 709 / 2020) and video / full range are taken from the file.
  • NVDEC hardware decoding. On NVIDIA GPUs, H.264, HEVC, VP9 and AV1 (AV1 needs an RTX 30-series or newer) decode on the GPU's video engine, freeing the CPU for playback, tracking and the UI. Frames go from the decoder straight into the cache in one copy. Formats NVDEC cannot handle (ProRes, 4:2:2 H.264, very large frames) and other GPUs decode on the CPU automatically, and a file that fails on the GPU mid-way switches to the CPU without losing your place. Toggle with Tools › Hardware Decoding (NVDEC); Properties shows which decoder each clip uses.
  • Cache memory. Tools › Cache Memory… sets the RAM for decoded frames (default: half of your RAM). The grey band on the scrub bar shows what is cached. CHARONOS reads ahead within the cache budget and keeps room for A, B and the next clip.
Tip. For heavy UHD material, keep NVDEC on and give the cache 8–16 GB. Use Tools › Clear Cache after replacing a file on disk.

17AI assistants (MCP)

CHARONOS has a built-in Model Context Protocol server (26 tools), so an AI assistant such as Claude can look at your frames and work with you: read the project, look at frames, write review notes, draw arrows, bookmark key poses, track a point and read its timing.

Connect Claude Code

Choose Tools › AI Assistant (MCP) › Copy Claude Code Setup Command and paste it into a terminal once. It looks like this:

claude mcp add charonos --scope user -- "C:\Users\you\AppData\Local\Programs\CHARONOS\charonos-mcp.exe"

Connect Claude Desktop or another MCP client

Choose Copy MCP Config (JSON) and add it to the client's MCP settings (for Claude Desktop: Settings › Developer › Edit Config):

{
  "mcpServers": {
    "charonos": { "command": "C:/Users/you/AppData/Local/Programs/CHARONOS/charonos-mcp.exe", "args": [] }
  }
}

The client starts charonos-mcp.exe, a small bridge that talks to the running CHARONOS and starts it if needed.

Example requests

  • “Look at frames 0–40 of the walk reference and write a note on each contact and passing position.”
  • “Track the ball, then bookmark its key poses and tell me where the spacing is uneven.”
  • “Compare my animation (B) with the reference (A) side by side and list the frames where the timing differs.”
Privacy and control. The connection is a local named pipe that only your Windows user account can open; CHARONOS itself sends nothing over the network. Frames and notes the assistant reads are passed to the AI service by your AI client, as with anything you share with it. Whatever the assistant does goes through the normal commands, so it appears on screen and can be undone with Ctrl+Z. If the assistant tries to open another project while yours has unsaved changes, CHARONOS asks you first. Turn the connection off with Tools › AI Assistant (MCP) › Allow AI Assistants to Connect.

18Animator workflows

Break down a reference

  1. Import the reference and set an In/Out range around the action (I, O, Ctrl+L).
  2. Track the key body part (hips for a walk, the wrist for a throw) with M and Ctrl+T.
  3. Open the Motion Graph, read the spacing chart and press Bookmark Keys.
  4. Play the poses with Ctrl+Space, adjust bookmarks with K, and write frame notes for contacts, extremes and breakdowns.
  5. Check the action on twos with Alt+2, and with video onion skin (2 before / 2 after, every 2 frames).

Review your animation against reference

  1. Import both; set the reference as A and your playblast as B (B badge), Side by Side Shift+2.
  2. Keep Sync B by Time on if the frame rates differ.
  3. Draw corrections on B and leave notes; export the compare layout as MP4 to share.

Assemble a selects reel

Open the Timeline panel, drag the best takes in, trim each to the useful action, split long takes with Ctrl+B and remove the rest. Export the timeline, or loop a section for study.

20Troubleshooting

ProblemWhat to do
A panel disappearedWindow menu, or Window › Reset Layout.
Playback stutters on UHDKeep Tools › Hardware Decoding on, raise Tools › Cache Memory, let the grey cache band fill, or turn on Playback › Skip Frames to Keep Up.
Colours look wrong on one fileCheck Properties › Pixel Format. Untagged HD video is treated as BT.709 and SD as BT.601, like most players. Try turning hardware decoding off to compare.
A file won't openOpen the Console (Ctrl+`) for the FFmpeg message. Re-wrap or re-encode unusual files with FFmpeg.
Sound is late or earlyAudio › Audio Offset… (positive values delay the picture).
Media offline after moving a projectKeep media next to the project, or locate the files when asked on open.
The AI assistant can't connectCheck Tools › AI Assistant (MCP) › Allow AI Assistants to Connect, make sure the path in the client config points to charonos-mcp.exe in the install folder, and restart the AI client. Only one CHARONOS window serves MCP at a time.
The Timeline panel is emptySources must be on the timeline: drag them from the Project View, or right-click a source › Add to Timeline.

21What's new in 1.1

  • Multi-track timeline: video tracks composited bottom to top, audio tracks, gaps that stay, overwrite or ripple editing, blade tool, snapping, linked picture and sound, copy / paste, nudge, disable, clip colours and exact clip properties.
  • Annotation clips: every drawing, text and shape appears as a clip on annotation lanes with its own icon — move, trim, cut, duplicate, recolour, lock; lanes can be hidden or locked. The red review marks stay.
  • Independent sound: sound clips with waveforms, gain line, fades, mute; track mute, solo and gain; playback and export use the same mix.
  • Compositing: opacity, Add / Screen / Multiply / Difference, picture-in-picture, fixed or automatic canvas.
  • Filter menu: silhouette, moving silhouette (background plate), edge lines, value, notan and motion highlight, live settings and export.
  • Navigation: edit points on every track, J / K / L shuttle with reverse play, mark clip, go to In / Out, a timecode readout in the timeline.
  • AI assistants: the timeline tool now places clips on tracks and sets their compositing and sound; new annotation_clips and set_filter tools.
  • Fixes: onion-skin ghosts of a clip stay under higher tracks; the regression checks grew to 65.

1.0

  • GPU colour conversion: frames are cached as Y′CbCr and converted on the GPU — about 60 % less cache memory, faster uploads.
  • NVDEC hardware decoding with automatic CPU fallback, direct copy into the cache, and a per-clip decoder readout.
  • Timeline panel (Window › Timeline, hidden by default): trimming, splitting, drag-and-drop reordering, snapping, thumbnails, waveforms and full undo.
  • Window menu: every panel and bar can be brought back; viewer-only and full-screen modes; layouts persist and can be reset.
  • Onion skin rebuilt to work like animation tools: key or frame-distance modes, separate before / after counts for drawings and video, step, falloff opacity, tint colours, optional display during playback.
  • Animator tools: Motion Graph with spacing chart and key-pose suggestions, frame notes with export, play on 2s/3s/4s, playback speed presets, mirror view and frame counter overlay.
  • AI assistants: built-in MCP server with 24 tools and the charonos-mcp.exe bridge.
  • Help: a searchable shortcut sheet that reflects your own key bindings, and this guide.
  • Uniform icons: every icon is normalised to the same size and stroke weight.
  • Stability: fixed a crash when editing the frame rate in Properties, safer cache limits, decoder fallback on GPU errors, out-of-memory handling in the decoder threads, validation of project files, and more regression tests (51).
