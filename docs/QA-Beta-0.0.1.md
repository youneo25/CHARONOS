# CHARONOS Beta 0.0.1

검증일: 2026-10-15 (Asia/Seoul).

- 기존 개발 버전 2.4.3의 기능을 기준으로 베타 버전 번호를 시작합니다.
- 앱 표시 버전: `Beta 0.0.1`. Windows 숫자 버전: `0.0.1.0`.
- GitHub 태그: `v0.0.1-beta`. 설치 파일: `CHARONOS-0.0.1-beta-Setup-x64.exe`.
- `build.bat`: Release 빌드 성공. 실행 파일의 FileVersion/ProductVersion 확인.
- `tools/test-features.bat`: 기존 기능 회귀 검사 40 passed, 0 failed, 0 skipped.
- 설치 프로그램은 Qt/FFmpeg/Microsoft C++ 런타임, 한국어 번역 및 라이선스를 포함합니다.
- 기존 설치 등록이 있는 PC이므로 자동 설치/제거 테스트는 기존 설치를 보호하기 위해 실행하지 않습니다. 패키지 실행 검증은 별도로 기록합니다.
- 소스와 빌드 중간 파일은 기존 작업 폴더에 유지하고 완성 설치 파일과 소스 ZIP은 F: HDD에 저장합니다.
