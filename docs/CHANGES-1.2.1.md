# CHARONOS 1.2.1

2026-11-08 (Asia/Seoul)

## 새 기능

- **비디오 다운로더**: 파일 메뉴에서 별도 창을 열어 YouTube, bilibili 등 yt-dlp 지원 링크를 다운로드합니다. 다운로드한 영상은 타임라인에 자동 삽입하지 않고 프로젝트의 Sources에 추가합니다.
- **Windows**: yt-dlp가 없으면 공식 최신 Windows 실행 파일을 앱 데이터 폴더에 준비합니다. 다운로드 진행률과 저장 위치를 창에서 확인할 수 있습니다.
- **Android (Lite APK)**: Termux에 설치된 yt-dlp를 백그라운드로 사용합니다. Termux와 yt-dlp 설치, 외부 명령 허용, Android의 Run Commands 권한이 필요합니다.
