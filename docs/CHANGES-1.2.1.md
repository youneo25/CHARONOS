# CHARONOS 1.2.1

## Video downloader

- Added **File → Video Downloader**, a dedicated window for links supported by yt-dlp, including YouTube and bilibili.
- Shows download progress and lets users choose a destination folder.
- Adds completed downloads to the project Sources list without placing them on the timeline.
- Windows prepares the official yt-dlp executable on first use.
- Android Lite delegates downloads to Termux and requires yt-dlp, shared-storage access, external-command access, and the Termux Run Commands permission.
