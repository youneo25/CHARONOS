# Keyframe Pro 2 기능 분석 및 CHARONOS 2.4.1 반영

조사일: 2026-10-15 (Asia/Seoul). 제품의 공식 문서를 기준으로 동작을 분석했습니다. 상용 실행 파일이나 내부 코드를 복사하지 않고 CHARONOS의 Qt/C++ 코드로 구현했습니다.

| 영역 | 공식 문서에서 확인한 동작 | CHARONOS 현황과 결정 |
|---|---|---|
| 주석 | 전경/배경 레이어, Hold Frames, Ghosting, 재생 중 표시 옵션 | 기존 펜·도형·텍스트·어니언 스킨·이전 키 유지 존재. 주석을 찍거나 편집한 키 위치에 빨간 눈금 표시 |
| 북마크 단계 재생 | Ctrl+Space로 북마크 이미지만 재생하고 다음 북마크까지 유지. FPS 영역에 Stepped 표시 | 새로 도입. 북마크 간 실제 프레임 간격을 유지. In/Out 범위와 타임라인의 여러 클립 지원. 화면 홀드 중 오디오는 끔 |
| 리뷰 탐색 | 북마크와 주석을 기준으로 탐색 | 기존 , / . 주석 이동에 더해 Shift+, / Shift+. 편집 키 이동 추가. 빈 삭제 키·수정 키·트래킹 수동 키와 A/B의 표시 가능한 키 포함 |
| 반복 리뷰 | 재생 범위 지정 및 반복 | 기존 In/Out 위에 주석/편집 구간 우클릭 반복 추가. 현재 클립과 다음 편집 키를 넘지 않는 범위, 단일 프레임 삭제 키도 지원 |
| Notes | 오른쪽 목록, 프레임별 메모 편집과 탐색, CSV 가져오기 | 별도 데이터 모델과 저장 형식 검증이 필요한 후속 후보. 이번 버전에 포함하지 않음 |
| FG/BG | 전경은 키별 주석, 배경은 모든 프레임에 고정 | 후속 후보. 현재 프로젝트의 주석 유지 규칙은 유지 |
| Maya 연동 / Python Client API | 플레이블라스트 및 외부 제어 | 후속 후보. 현 버전의 직접 Maya 연동은 없음 |
| 뷰어 / 출력 | A/B, 탐색, 프레임 이동, 단축키 설정, 파일 내보내기 | 이미 구현되어 있으며 이번 요청에서는 리뷰 표시와 재생 안정성에 집중 |

## 표시 규칙

- 2.4.1에서는 사용자 요청에 따라 구간 채우기를 제거했습니다. 주석을 찍거나 편집한 키 위치만 표시하며, 상단 빨간 눈금은 3×10px, 하단은 2×4px입니다.
- 빈 키(주석 지움)도 해당 프레임에 눈금을 표시합니다. 주석이 이어져 보이는 중간 프레임은 칠하지 않습니다.
- 트래킹은 수동 배치/수정 키에만 눈금을 표시합니다. 키로 저장되지 않는 뷰어 설정은 표시 대상이 아닙니다.
- 정확한 키 프레임의 현재 숫자만 연한 민트 #A6DCB5, 나머지 프레임은 기존 글자색입니다.
- B의 표시 가능한 키는 현재 비교 설정의 시간/FPS 매핑으로 A 재생 위치에 투영합니다. A가 짧아 마지막 이미지를 유지하는 동안에도 상단 재생바는 전체 비교 길이를 탐색합니다.

## 사용법

- K: 현재 프레임 북마크 추가/삭제.
- Ctrl+Space 또는 Ctrl+재생 버튼: 북마크 단계 재생/정지. Space: 일반 재생/정지.
- Shift+, / Shift+.: 이전/다음 편집 키. 기존 , / .: 이전/다음 비어 있지 않은 주석 키.
- 재생바 우클릭 > 이 주석 / 편집 구간 반복. Alt+X: 반복 범위 해제.
- Home / 처음 버튼, End / 끝 버튼: 재생을 정지하고 해당 위치로 이동. 오디오도 함께 정지.
