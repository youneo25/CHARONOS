# CHARONOS 1.2.2

## Drawing and review

- Added Drawing Mode. When enabled, annotations are visible and editable only on their explicitly drawn frames; the default held-exposure behavior remains available by turning the mode off.
- Added the Drawing Mode choice to the first-run guide and Settings.
- Applied the same one-frame exposure behavior to video and still-frame exports.
- Updated the first-run guide to open the existing offline User Guide, in English for either interface language.

## Video downloader

- Added link analysis with a thumbnail and video details such as resolution, aspect ratio, frame rate and duration.
- Added maximum-resolution selection after analysis and a Native source-resolution button.
- Improved downloader progress layout and dialog spacing.

## Settings and viewing

- Consolidated application preferences under **Edit → Settings**, including language, hotkeys, Drawing Mode, decoding, cache and update options.
- Added Factory Reset, with a confirmation prompt; project files remain untouched.
- Added View Mode, an always-on-top toggle and F11 viewer-only full screen.
- Fixed narrow keyboard-shortcut columns in the HTML User Guide.

## Documentation

- Refreshed the User Guide and README for the new settings, Drawing Mode, downloader resolution controls and 1.2.2 release.
