# CHARONOS Beta 0.0.1 (C++ / Qt6 / FFmpeg / OpenGL)

## Beta 0.0.1

- 기존 2.4.3 기능을 기준으로 첫 베타 버전으로 변경했습니다.
- 앱 표시 버전: Beta 0.0.1. 설치 파일: CHARONOS-0.0.1-beta-Setup-x64.exe.

## 2.4.3 업데이트 (이전 개발 버전)

- Tracking > Tracking Manager에서 매니저를 표시/숨김. 현재 편집 중인 A/B 클립의 트랙을 선택하고 트랙별 마커·경로 표시와 ‘생성 이전 숨김’을 켜고 끌 수 있습니다. 전체 오버레이 표시도 매니저에서 제어합니다.
- 트랙은 기본적으로 생성 프레임 이전에 보이지 않습니다. 역방향 추적이나 마커 보정 후에도 처음 생성한 프레임을 유지합니다. 트랙별 옵션은 프로젝트 저장·실행 취소/다시 실행·이미지/영상 내보내기에 반영합니다. 이전 프로젝트는 가장 이른 수동 키를 생성 프레임으로 사용합니다(수동 키가 없으면 가장 이른 추적 지점).
- 텍스트 Inspector의 글꼴 목록에 실제 화살표 버튼을 추가했습니다. 불투명도는 0–100% 슬라이더와 대비가 높은 숫자 입력칸으로 조절합니다.
- 검증: [docs/QA-2.4.3.md](docs/QA-2.4.3.md).

## 2.4.2 업데이트

- 스페이스 재생 직후 수십 프레임을 건너뛰던 문제를 수정했습니다. 기존 오디오 시계 경로가 ‘프레임 건너뛰기’ 설정을 무시했습니다. 꺼져 있을 때는 다음 프레임으로 순서대로 진행하며 큰 오디오 지연은 현재 영상 위치에 다시 맞춥니다.
- 실제 재현: 240fps / 첫 타이머 350ms 지연에서 수정 전 0→77, 수정 후 0→1. 현재 위치에서 이어 재생하는 동작과 명시적으로 켠 In/Out 반복은 유지합니다.
- 오디오 위치 단위·오류를 검사하고, 이전 장치 값이나 비정상 값으로 새 세션의 재생 위치가 튀지 않도록 제한합니다. 정지 상태에서는 무음 버퍼를 계속 보내지 않습니다.
- 비동기 오디오 디코딩 완료 시 파형/속성 갱신을 끝낸 뒤 표시된 프레임에 맞춰 소리를 시작합니다.
- 검증: [docs/QA-2.4.2.md](docs/QA-2.4.2.md).

## 기능

- 여러 소스를 한 프로젝트에: 프로젝트 뷰(SOURCES / TIMELINES), 타임라인은 클립을 이어 붙여 재생
- 프레임 단위 정확 디코딩, 프로젝트 전체가 RAM 캐시 하나를 공유
- 주석: 펜슬, 지우개, 텍스트, 화살표, 직선, 사각형, 원 (클립마다 따로 저장)
  - 키 방식: 주석이 없는 프레임에 그리면 새 키가 생기고, 이전 키의 주석은 그 프레임부터 사라짐
    (편집 > 이전 주석에 이어 그리기 로 이전 주석 유지 가능). 이어받아 보이는 주석을 지우거나 고치면 현재 프레임에 새 키가 생김
  - 선택(V): 클릭 / 범위 드래그 / Shift 추가, 이동 · 크기 · 회전(Shift 15° 단위), 복사 / 붙여넣기, 색 · 굵기 바로 적용
  - 텍스트(T): 화면에서 바로 입력, Shift+Enter 줄바꿈, 더블클릭으로 다시 편집
  - 펜슬은 판 타블렛 · 액정 타블렛 펜일 때만 필압 적용 (마우스는 균일한 굵기). 선은 곡선으로 다듬고 MSAA로 가장자리를 부드럽게 그림
  - 굵기 0.5–200px · 불투명도 1–100% · 글자 크기 6–600px 자유 값 + 프리셋
  - 어니언 스킨(Shift+O): 이전 키는 붉게, 다음 키는 푸르게, 개수 조절, 영상 앞뒤 프레임 겹쳐 보기
- 모션 트래킹(M): 점을 찍고 Ctrl+T(앞) / Ctrl+Shift+T(뒤)로 추적, 프레임마다 위치를 이어 마야 모션 트레일처럼 커브 표시
  선택 도구(V)로 마커를 클릭해 선택 후 Delete로 트랙 삭제
  마커를 드래그해 보정하면 그 프레임이 키가 되고 다음 추적은 키를 넘지 않음. 프레임 번호 옵션, 내보내기에 포함 가능
  커브 표시: 지나간 경로만(기본 5초, 1/2/3/5/10초, 오래될수록 흐려짐) 또는 전체 경로 — Shift+M으로 전환. 트랙이 끝난 자리는 붉은 점과 "끝 · 프레임"으로 표시
  어니언 스킨 버튼: 클릭으로 켜고 끄기, 오른쪽 클릭으로 설정 (비디오 > 어니언 스킨 설정)
- 북마크, In/Out 반복, 클립 간 이동
- A/B 비교: 와이프(경계 드래그), 좌우, 위아래, 겹쳐 보기 50%, A/B 바꾸기
  - 프로젝트 뷰와 타임라인 패널의 각 소스 줄에 있는 A / B 버튼으로 바로 지정 (B를 다시 누르면 비교 끄기)
  - 비교 중에는 A 클립만 재생하고, B는 시간 기준으로 자기 FPS대로 재생 (비디오 > 비교 > FPS가 다르면 시간으로 맞추기, 끄면 프레임 번호 기준)
  - B 쪽을 클릭하면 B가 편집 대상 (주석, 선택·변형, 지우개, 텍스트, 복사·붙여넣기, 트래킹, 어니언 스킨, 우클릭 메뉴, 되돌리기). 와이프는 경계 오른쪽이 B, 겹쳐 보기는 Shift+Tab(비교 > B에 주석)으로 전환. 편집 중인 쪽은 라벨 테두리로 표시
  - B의 주석은 타임라인에도 표시되고, 내보내기에서 'A / B 비교 화면'을 켜면 화면 배치 그대로(주석·트래킹·B 소리 포함) 저장
  - 재생 길이는 A와 B 중 긴 쪽. A가 먼저 끝나면 A는 마지막 프레임에 멈춰 있고 B가 계속 재생됨
  - 긴 소스 이름은 가운데를 줄여 표시 (전체 이름과 경로는 툴팁)
- 내보내기: MP4 H.264(CPU) / H.264·H.265(NVENC) / MOV ProRes 422 HQ / PNG·JPG·TIFF 시퀀스
  전체·현재 클립·In/Out 범위, 출력 FPS, 크기, 주석 포함, 클립 이름과 프레임 번호 표시
  오디오 포함 (MP4: AAC 256k, ProRes MOV: 16bit PCM). 출력 FPS가 원본과 다르면 소리도 같은 비율로 늘어나거나 줄어듦
- 오디오: 프레임마다 실제 타임스탬프(PTS)로 소리 위치를 계산 (VFR 휴대폰·화면 녹화 영상도 정확). 영상의 소리를 미리 풀어 두고 Windows 기본 출력(waveOut)으로 재생. 소리가 있으면 사운드 카드 시계가 기준이고 화면은 지금 들리는 프레임을 보여줌 (In/Out 반복 지점에서 소리와 화면이 같이 넘어감)
  - 재생 FPS를 바꾸면 소리도 그 속도로 (테이프처럼 음높이 변화)
  - 프레임을 넘기거나 스크럽할 때, 그 프레임이 화면에 나타나는 순간 소리를 짧게 들려줌 (Audio > Scrub Audio)
  - 비교 오디오 (Audio > Compare Audio): 자동(A에 소리가 있으면 A, 없으면 B) / A / B. B 소리를 들을 때도 그 소리에 맞춰 화면이 움직임
  - 볼륨 슬라이더 · 소리 끄기 (Ctrl+M), 볼륨 Ctrl+↑ / Ctrl+↓, Audio > Audio Offset (ms)로 출력 지연 보정
  - 하단 타임라인에 오디오 파형 표시
- `.frvm` v4 저장 (v3 `.frvm`과 이전 Electron `.json`도 읽음)

## 마우스

- Alt + 왼쪽 드래그: 어디서든 재생 위치 이동 (오른쪽 = 앞으로, Shift를 더 누르면 천천히)
  커서가 모니터 끝에 닿으면 반대편으로 넘어가 끝없이 드래그 (가운데 버튼 화면 이동도 동일)
- 가운데 버튼 드래그: 화면 이동, 휠: 확대 / 축소
- 오른쪽 클릭: 빈 화면(붙여넣기, 도구, 어니언 스킨, 비교, In / Out, 북마크…), 주석(복사, 색상, 굵기, 순서, 잠금, 삭제), 트래킹 마커(추적, 앞 / 뒤 지우기, 이름, 색, 삭제),
  타임라인 · 클립 바(In / Out, 북마크, FPS), 프로젝트 뷰 · 소스 목록(A / B, 순서, 탐색기, 제거)

src/media/AudioClip           오디오 트랙 전체를 48 kHz 스테레오 16bit로 디코딩
src/media/AudioEngine         waveOut 출력, 가변 속도, 짧은 스크럽 소리

src/model/Sequence            뷰어가 재생하는 것(타임라인 또는 클립 하나): 전체 프레임 → (클립, 클립 프레임)
src/model/Track             트랙 데이터와 모션 트레일 그리기
src/track/Tracker            ZNCC 템플릿 매칭 점 추적 (서브픽셀, 속도 예측, 키 템플릿 혼합)
src/ui/StrokePanel           굵기 · 불투명도 · 글자 크기 팝업
src/export/VideoEncoder       libavcodec 인코더 (libx264 / h264_nvenc / hevc_nvenc / prores_ks)
src/export/Exporter           뷰어 캐시와 별개로 디코딩 → 주석 합성 → 인코딩 (작업 스레드)
src/ui/Palette, Style, Icons  색상 토큰, 스타일시트, SVG 선 아이콘
src/ui/Viewport               OpenGL 텍스처 2장(A/B) + QPainter 오버레이
src/ui/Timeline               하단 스크럽 바와 상단 클립 바
src/ui/MainWindow             레이아웃, 메뉴, 재생 시계, 실행 취소, 가져오기/저장/내보내기
tools/frame_verify            프레임 정확성 검증 (순차 vs 무작위 탐색 vs ffmpeg select=eq(n,i))
tools/track_test              트래커 정확도 측정
tools/pressure_test           필압 선 렌더링 확인 (PNG 출력)
tools/audio_test              오디오 디코딩 시각과 재생 시계 확인
